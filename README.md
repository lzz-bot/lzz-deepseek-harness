# lzz-deepseek-harness

DeepSeek Harness plugin collection. Each plugin is maintained in its own repository and tracked here as a git submodule.

## Plugins

- [dsh-clean-archived-sessions](https://github.com/lzz-bot/dsh-clean-archived-sessions) — clean up archived, unlisted, and empty DSH sessions by permanently deleting them.

## Clone

```bash
git clone --recurse-submodules https://github.com/lzz-bot/lzz-deepseek-harness.git
```
